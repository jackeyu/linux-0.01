# Linux v0.0.1 (1991)

This repository serves as a personal historical archive and backup of the **Linux kernel version 0.0.1**, originally released by Linus Torvalds in September 1991.

## 📜 About Linux 0.0.1
* **Release Date:** September 17, 1991
* **Original Target:** Intel 386 architecture
* **Significance:** The very first public milestone of the Linux operating system, containing the foundational kernel architecture, task switching, and basic terminal I/O.
